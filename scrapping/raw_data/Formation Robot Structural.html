Formation Robot Structural

Étude d’un bâtiment R+5

Introduction

Le système Robot est un logiciel CAO/DAO destiné à modéliser, analyser et dimensionner les différents types de structures. Robot permet de modéliser les structures, les calculer, vérifier les résultats obtenus, dimensionner les éléments spécifiques de la structure ; la dernière étape gérée par Robot est la création de la documentation documentation pour la structure structure calculée calculée et dimensionnée.   On va essayer de faire ensemble un exemple détaillé de avec Autodesk RSAT 2010. Il s’agit d’un bâtiment R+5.   Implantée à Sétif (zone IIa), usage d’habitation, structure mixte (voiles plus portiques en BA).
