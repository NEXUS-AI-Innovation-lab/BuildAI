Lorsqu’une construction est envisagée sur un terrain de nature particulièrement compressible, que les charges ponctuelles apportées par la structure sont élevées et que les tolérances de déformation sont très faibles, la mise en place de fondation profondes type pieux est une solution efficace.

Tout type d’ouvrage peut être fondé à l’aide de cette technique : bâtiments, ouvrages d’art, infrastructures diverses.  

Les pieux peuvent également être utilisés pour créer des parois de soutènement : paroi de pieux disjoints ou paroi de pieux sécants.  

Keller a les capacités pour réaliser tout type de pieux : les pieux à la tarière creuse, les pieux vissés moulés (type INSER®), les pieux forés simples ou les pieux forés tubés.  

La liaison avec la structure se fait par l’intermédiaire d’une tête de pieu pour un pieu isolé, ou à l’aide d’un chevêtre en béton armé pour un groupe de pieux.  

Selon le type d’effort appliqué (compression simple, ou torseur d’efforts complexe), les pieux peuvent être armés toute hauteur ou partiellement, ou simplement équipés de barres d’attente.
